# PDF Resources - How to Add Your PDFs

This directory contains the actual PDF files that users can download from your website.

## Required Files

Place these PDF files in this directory:

1. **startup-checklist.pdf** (12 pages)
   - Complete Startup Launch Checklist
   - Include: LLC formation, EIN registration, banking setup, legal compliance

2. **tax-guide-2025.pdf** (24 pages)
   - Small Business Tax Guide 2025
   - Include: Tax brackets, deductions, quarterly taxes, S-Corp vs LLC

3. **marketing-playbook.pdf** (18 pages)
   - Zero-Budget Marketing Playbook
   - Include: Social media calendar, SEO strategies, email templates

## Quick PDF Creation Options

### Option 1: Create with Google Docs
1. Go to docs.google.com
2. Create your content
3. File → Download → PDF Document (.pdf)
4. Rename and place in this folder

### Option 2: Create with Canva
1. Go to canva.com
2. Search "Document" template
3. Design your guide
4. Download as "PDF Print"
5. Place in this folder

### Option 3: Use AI Tools
- Use ChatGPT, Claude, or similar to generate content
- Format in Google Docs or Word
- Export as PDF

### Option 4: Placeholder for Testing
For testing purposes, you can create simple placeholder PDFs:
1. Open any text editor
2. Write basic content
3. Print to PDF (Ctrl+P → Save as PDF)
4. Name appropriately and place here

## File Naming
- Must match exactly: `startup-checklist.pdf`, `tax-guide-2025.pdf`, `marketing-playbook.pdf`
- All lowercase with hyphens
- No spaces or special characters

## Testing
After adding PDFs:
1. Visit http://localhost:5175/resources
2. Click on any resource
3. Enter email (any email for testing)
4. Click "Download Now"
5. Verify PDF downloads correctly
